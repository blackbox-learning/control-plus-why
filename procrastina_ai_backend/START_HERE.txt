🔑 OPENAI API KEY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to https://platform.openai.com/api-keys
2. Sign in or create account
3. Click "Create new secret key"
4. Copy the key (looks like: sk-xxxxxxxxxxxxxxx)
5. Add to .env file:
   OPENAI_API_KEY=sk-xxxxxxxxxxxxxxx


🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "connect ECONNREFUSED 127.0.0.1:3306"
   └─ MySQL not running. Start it:
      Windows: mysql.server start
      Mac: brew services start mysql
      Linux: sudo systemctl start mysql

❌ "Access denied for user 'root'@'localhost'"
   └─ Wrong MySQL password. Check DB_PASSWORD in .env

❌ "Unknown database 'procrastina_ai'"
   └─ Run schema: mysql -u root -p < database/schema.sql

❌ "OPENAI_API_KEY is undefined"
   └─ Add key to .env: OPENAI_API_KEY=sk-xxxxx

❌ "Cannot find module 'express'"
   └─ Install: npm install

❌ "Port 5000 already in use"
   └─ Change PORT in .env to 5001 or higher

See QUICKSTART.md for more solutions.
